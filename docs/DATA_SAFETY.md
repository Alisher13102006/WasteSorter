# Форма Data Safety (Google Play), задание 8

| Вопрос формы | Ответ |
|--------------|-------|
| Собирает ли приложение данные пользователей или передаёт их? | Да |
| Шифруются ли данные при передаче? | Да (HTTPS / TLS) |
| Можно ли запросить удаление данных? | Да (через раздел поддержки) |

## Типы данных
| Категория → тип | Собирается | Передаётся третьим лицам | Обязательно | Цель |
|-----------------|-----------|--------------------------|-------------|------|
| Сведения о приложении и производительности → Журналы сбоев | да | нет* | да | аналитика |
| Сведения о приложении и производительности → Диагностика | да | нет* | да | аналитика |
| Действия в приложении → Взаимодействие с приложением | да | нет* | да | аналитика |
| Идентификаторы устройства → Firebase installation ID | да | нет* | да | аналитика |
| Фото и видео → Фотографии | **нет**** | — | — | — |

\* Google (Firebase) обрабатывает данные от нашего имени. По правилам Google Play это не считается передачей третьим лицам.
\** Фото обрабатываются на устройстве и не покидают его. По правилам Play такие данные не декларируются как собираемые.
