# Работа с обращениями (задание 15, часть А)

Трекер — GitHub Issues с шаблонами `.github/ISSUE_TEMPLATE` (баг с фото предмета, пожелание, вопрос).
Метки: `P0`–`P3`, `triage`, `model` (ошибка распознавания). Отзывы — Play Console → Оценки и отзывы.

## Приоритеты и SLA
| Приоритет | Критерий | Первый ответ | Решение |
|-----------|----------|--------------|---------|
| P0 критический | крэш у многих, уязвимость, утечка данных | 2 ч | hotfix ≤ 24 ч |
| P1 высокий | распознавание не работает совсем, камера не открывается | 1 рабочий день | PATCH ≤ 7 дней |
| P2 средний | модель регулярно путает класс, неудобство | 3 рабочих дня | ближайший MINOR (дообучение модели) |
| P3 низкий | пожелание, косметика | 5 рабочих дней | backlog |
| Отзыв в магазине | любой | 2 рабочих дня | — |

## Ответы на отзывы
- ★☆☆☆☆ «Обновился — приложение вылетает при запуске».
  Ответ: «Извините за неудобство! Ошибка версии 1.2.0 исправлена в 1.2.1, она уже в Google Play.
  Обновите приложение, пожалуйста. Если сбой повторится, напишите нам через раздел поддержки».
- ★★★★☆ «Классно, но банку из-под колы считает пластиком».
  Ответ: «Спасибо! Пока приложение знает три вида отходов: пластик, стекло и бумагу. Металл добавим в
  следующей большой версии. Сейчас для неизвестных предметов приложение старается отвечать „не уверен“».
